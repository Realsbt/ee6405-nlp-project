# 文献与研究定位

检索日期：2026-11-06。使用本地 literature-review skill 的来源核验、范围声明和证据分级流程。这是一轮针对性叙述检索，不是穷尽检索或系统综述；未做双人独立筛选，不提供虚构的 PRISMA 数量。代码遵循 ponytail 的复用与最小实现原则。

## 建议的核心问题

**在来源组隔离、相同可见正文和固定低误报阈值下，篇章关系是否提供超出文本表征与 EDU 聚合的检测增益？这种增益能否跨领域、跨编辑过程保留？**

四分类、图网络、对比学习、分组划分都不能单独作为新颖性主张。更有价值的路线是可核验的来源标签、信息预算公平的机制对照，以及编辑场景中的迁移失败与误报分析。当前证据支持研究这个问题，不支持宣布已经回答了结构机制问题或保证发表。

## 扩展优先级

1. 已执行：原始来源审计、验证集锁阈值、MixSet保守迁移测试。
2. 下一步：LF-Motifs或简单长度/风格诊断，加同窗口EDU pooling。前者需要解析资源；长度诊断不需要GPU，但不能称为LF-Motifs复现。
3. GPU可用后：完成机制消融、留域；补一个Fast-DetectGPT或Binoculars分数基线，比同时堆多个同类编码器更能覆盖方法差异。
4. Beemo优先于自行生成全新基准；先核验来源、许可、组划分、标签兼容性及已训练检测器是否见过数据。
5. 只有现有数据不支持“同一底稿、多编辑者、受控编辑强度”时，再构建小型配对研究集。新集建设标准见05。
