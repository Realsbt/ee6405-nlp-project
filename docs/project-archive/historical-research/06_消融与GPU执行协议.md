# 消融与 GPU 执行协议

日期：2026-11-06；实现状态更新至2026-11-09。已有结果与计划严格分开。四条件训练入口及CPU单步反向验收已完成，正式新增神经实验仍未执行，见13号文档。

## 已有实验覆盖

RoBERTa / RACE × CE / CE+SupCon × 3种子共12次神经训练，另有TF-IDF。可分析架构与损失的联合表现，但由于全文图、pooling及容量差异，不能称为篇章关系的因果隔离。

## 第一阶段：主机制对照

统一RoBERTa tokenizer的512-token预算，先确定可见正文，再只解析这段正文。不可从全文树剪枝后宣称没有全文信息。所有方法使用相同样本、预训练revision、微调层、batch、优化步数上限、开发集选模规则和CE目标。

| 条件 | 改动 | 回答的问题 |
|---|---|---|
| A | RoBERTa文本编码，原基线pooling | 文本基线 |
| B | 可见正文RST图RACE | 相同信息预算下结构模型表现 |
| C | B的逐图关系类型置换，拓扑不变 | 关系类型是否有用 |
| D | 同EDU切分、同token表示，EDU pooling与匹配分类头，无GNN消息传递 | 增益是否仅来自切分与聚合 |

固定种子3407、42、2026，共12次训练。主要预设比较B-D、B-C；B-A回答总体收益，不单独证明机制。报告参数量；匹配分类头不等于严格等容量。

C不能是全局关系名替换，因为可学习参数能适应一一重命名。用与标签无关、由item_id和固定种子决定的逐图关系置换，保留关系频数，并同步更新关系节点和依赖其类型的边。记录单一关系或置换后未变化图的比例。

## 第二阶段：按问题追加，不做无界笛卡尔积

| 对照 | 固定项/注意事项 | 依赖与优先级 |
|---|---|---|
| 全文图 vs 可见窗口图 | 同parser版本；保留全文结构是额外信息条件，不是公平主对照 | 第一阶段之后，量化旧协议影响 |
| 单关系图 vs 关系类型图 | 保留连接结构，参数规模变化需报出 | 区分关系语义与连接 |
| 拓扑扰动 | 保留EDU集合、节点数和边数；最好限制为合法树/保持度分布；报告扰动失败 | 不与关系类型扰动混称 |
| root/mean/EDU pooling | 统一编码器与分类头；每个条件重训 | 排除读出方式影响 |
| GNN深度0/1/2 | 0层需定义残差与投影，报告训练参数和耗时 | 第一阶段显示结构收益后 |
| CE vs SupCon | 同batch组成与优化步数；loss权重、温度只能开发集选择 | 在公平窗口协议下复核旧结论 |
| 微调层/可训练参数匹配 | 相同调参预算；不是纠正“原论文全层微调” | 次要敏感性 |
| parser失败/低质量子集 | 不能静默丢弃；记录失败率并报全量与条件结果 | CPU可先做 |
| 长度/领域/编辑者类型分层 | 区间固定、支持数明确；探索性分析 | CPU现成预测可做 |

更换结构后只对旧checkpoint推理可称“扰动敏感性”，不能等同训练消融。长度截断、关系随机化与换pooling都可能引起分布变化，不能过度作因果解释。

## 第三阶段：泛化

留一领域主队列：RoBERTa+SupCon与RACE+SupCon × 4目标领域 × 3种子 = 24次。目标域不得参与训练、开发、阈值校准；同来源关联组跨域时整体隔离。每次保存类别支持数和来源组数。所有目标域测试完成后统一汇总，不能只报告成功领域。

生成器/编辑者留出在原始metadata审计后另冻结协议；处理一条底稿对应多个编辑器造成的家族泄漏。额外不同原理基线先选Fast-DetectGPT或Binoculars之一，先在二分类赛道评测。大模型推理需要显存不等于需要从头训练。

## 启动验收门槛

- CPU：证明不同条件可见token完全一致；解析缓存不能读到窗口外正文；分组无交集；控制图合法、扰动确定且与标签无关；不同条件输出shape和有限梯度检查。
- 模型：只从共同基础权重开始新增消融，不偷用已看过测试的最佳checkpoint热启动某一条件。
- 运行：train/dev smoke后冻结配置、数据/缓存/代码哈希、选模和失败处理；不要用测试集调显存参数以外的研究设置。
- 产物：配置、种子、环境、每epoch开发曲线、best checkpoint及哈希、逐样本测试概率、混淆矩阵、阈值记录、成本、失败记录。
- 分析：预设主要比较，按来源组配对区间、报告三种子差值，不把0.4个百分点自动称为显著。
