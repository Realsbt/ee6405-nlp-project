## 1. 当前基线究竟定了没有

建议在下一轮协议冻结时明确以下角色，保留现有结果，不再反复换参照物：

| 角色 | 模型 | 用途 |
|---|---|---|
| 轻量基线 | TF-IDF + logistic regression | 判断词汇线索有多强、成本有多低 |
| 主机制基线 | RoBERTa + CE | 与固定CE的新结构对照公平比较 |
| 已有强比较对象 | RoBERTa + CE/SupCon | 现有三种子平均Macro-F1最高的配置 |
| 待解释的复现模型 | RACE | 检验复杂篇章结构是否值得使用 |

“选择这些基线”与“最终协议全部冻结”是两件事。目前模型角色可确定，但同窗口输入、选模/校准分区、训练入口与预算还没全部落地。历史91.15%只能作原协议结果，不能当新公平协议下已经重训完成的分数。

## 2. 现在已经挖出的线索

1. **不是只有一个坏种子拖累总体。** 六个同损失/同种子比较中，RACE的Macro-F1均低于RoBERTa，差为-1.857/-0.385/-0.152及-0.587/-0.486/-1.280个百分点。但这不等于统计证明结构无效。
2. **writing域最值得先查。** 两种损失三个种子的准确率差都为负；SupCon下该域纯人类文本召回差为-4.02/-2.51/-4.52个百分点。优先检查哪些writing样本被错分成哪些类别，以及对应EDU/关系是否可信。
3. **存在解析质量线索，但未证实因果。** CE在有span缺口样本上三次均更差，无缺口样本总体退化较小；SupCon没有同样整齐的趋势。span缺口是字符覆盖问题，不等于关系语义标注错误。
4. **不能只怪截断。** 当前截断组差异较小，主要退化反而在未截断组。这只是分组关联，截断仍可能与领域、长度、图复杂度混杂。
5. **小类别有明显种子波动。** humanized仅227条，其中真人57条；CE召回差会从负翻正。需要保留全部种子与支持数，不能挑有利种子解释机制。
6. **模型错误并非完全相同。** 每个比较中RACE独对58–86条，RoBERTa独对72–112条。这可支持在开发集研究互补性，但测试集上的oracle选择不是可部署算法，不能拿来当融合结果。

本轮没有进行p值搜索或用这些切片挑选新超参数；不能以本次观察宣布发表级因果发现。

## 3. 如何把线索变成原因证据

| 假设 | 现在CPU可做的具体检查 | 确认性实验 | 什么结果才支持 |
|---|---|---|---|
| parser误差损伤RACE | 在开发集按领域/长度抽取图，盲审EDU边界、覆盖、关系；记录双人分歧或单人审查限制 | 同文本、同切分条件比较正常关系与控制关系；质量子集作预先规定分析 | 高质量关系条件的收益稳定，且域/长度混杂不能解释 |
| EDU聚合本身已足够 | 固定可见正文与EDU，检查节点/token对齐 | 同窗口EDU pooling与RGCN分别重训 | pooling不劣或更好且成本较低，支持简化，不等于所有图无用 |
| 关系类型没用 | 确认置换是逐图且独立于标签，而非全局改名 | 正常类型 vs 每图类型置换，保持拓扑、EDU和训练预算 | 正常类型稳定更好，才支持类型语义有价值 |
| 拓扑没用 | 构造保持节点与边数的重连，检查断连、自环与度分布 | 正常拓扑 vs 预先固定的随机重连，单独报告控制保留性质 | 正常图稳定更好才支持对应拓扑信息；重连也可能造成分布偏移 |
| 容量/优化导致差异 | 统计可训练参数、梯度范数、开发集学习曲线与早停点 | 等预算调参，必要时参数量相近MLP控制 | 差距随优化修正消失，说明旧比较含训练混杂 |
| 域依赖或捷径 | 按domain×class比较；只在训练/开发集探查词汇与长度关联 | 留一领域，目标域不参与选模；比较ERM和域平衡训练 | 未见域/最差域改善且平均性能可接受 |

这些是后续步骤，不表示表中全部CPU审查或代码已完成。优先做4条件×3种子的核心消融；拓扑和容量控制作为第二阶段，不能把“关系类型置换”说成已覆盖所有结构消融。

已有测试集只能用于透明探索；确认实验须预先冻结方案，优先用新外部样本或未参与开发的来源组。若仍使用同一HART测试集，应明确为后验补充分析。

## 4. 三个优先候选算法

### A. 无GNN的EDU层级聚合：首选机制实验

结构：同512-token正文 → RoBERTa token表示 → EDU内均值 → EDU间均值或单层attention → 四分类头。

- 为什么可能可行：保留局部片段聚合，减少对关系标签与图传播的依赖；参数与训练复杂度更小。层级聚合有文档分类方法基础[2]，但本项目有效性仍是待检验假设。
- 最便宜的验证：先固定EDU均值版本作为消融，不同时搜索很多attention结构；三种子与正常图配对。
- 何时有价值：分数相近但更低成本、更稳定，或者外部迁移更好，都可形成可解释结果。
- 风险：仍依赖EDU边界；短文本不一定有优势。不能把删GNN后的旧checkpoint直接当成重训版本。
- 资源：CPU准备缓存和测试；训练及完整多种子确认建议GPU。

### B. 篇章统计特征 + 线性分类器：便宜的结构基线

结构：同窗口图 → EDU数/长度分布、树深、关系比例及经核对的motif特征 → 标准化 → 正则化多分类logistic regression。

- 为什么可能可行：如果有用信息主要是结构分布，未必需要可训练图网络。Threads of Subtlety[1]在二分类检测中研究层级篇章特征，提供方向依据，不是四分类获胜的证据。
- 最便宜的验证：先实现明确列出的简单统计特征；特征标准化、筛选和正则强度只在train/dev上拟合。记录长度特征单独基线，排查是否只在识别文本长度。
- 名称边界：简单统计特征版不是“复现LF-Motifs”；只有真正实现论文定义的motif与对应流程，才使用该名称。
- 风险：可能学习领域/长度捷径，且仍受parser错误影响；解析时间必须计入成本。
- 资源：已有解析可支持CPU小模型训练，但与同窗口主表比较前仍需生成同窗口解析。当前尚未实现或训练。

### C. 域平衡RoBERTa，再考虑GroupDRO：优先针对泛化问题

结构：保持文本模型不变，先做domain-balanced sampling；若开发证据支持，再用预定义domain或domain×class组的GroupDRO目标。

- 为什么可能可行：本轮观察到writing域稳定退化，说明全局均值不足以描述表现。GroupDRO[3]针对预定义组的最差风险，提供训练目标上的替代；原文强调正则化/早停的重要性。
- 注意推断边界：RACE相对RoBERTa在writing差，并不证明RoBERTa自身因域不平衡而失败；这是值得验证的候选，不是诊断出的病因。
- 最便宜的验证：先比较ERM与域平衡采样，避免直接增加复杂优化；报告所有域、worst-domain指标和平均指标，不能只报改善的域。
- 风险：HART域规模接近，简单平衡可能几乎无效；domain×class小组可能高方差。已知组鲁棒不保证未见域鲁棒，必须留域评测。
- 资源：CPU检查组与采样；神经训练建议GPU。

## 5. 暂不优先，但可以有条件拓展

- **开发集概率融合**：错误有互补性，可在开发集拟合RoBERTa/RACE固定权重凸组合，然后独立校准、冻结测试。作为强工程比较对象，不自动是算法创新；推理需要两模型及parser，成本上升。目前未运行，不能报oracle收益。
- **长文本chunk/层级模型**：只有先确认长文有稳定失败才优先投入。当前截断组不是主要相对退化来源；如果扩大文本预算，必须另开长窗口赛道，不与512预算混称公平。
- **creator辅助任务**：可对兼容的creator标签添加辅助损失，但从四类概率相加已经能得到creator分数；需证明额外训练目标有价值。不要把标签硬拆成人/AI编辑者二乘二。
- **Fast-DetectGPT/Binoculars**：不同原理的二分类对照可补充，但不能未经适配混进四分类主表，模型推理可能需要额外GPU。已有文献见04。
- **LLM as a judge**：用于抽样检查语义保持与改写质量，不能判定真实作者或替代来源标签；需要人工抽查一致性、固定prompt/模型版本及成本记录。不是解决当前机制混杂的第一优先级。

## 6. 推荐研究主线与决策

先保持RoBERTa主基线，完成EDU pooling和关系控制；若简单聚合同样有效，论文重点可以是“哪些结构成分必要、成本和泛化如何”，不必强行发明更复杂模型。若结构确有稳定增益，再投入拓扑控制与跨域确认。若外部性能持续差，报告适用边界，而不是只在域内追0.5个百分点。

训练与评测框架：来源组隔离 → 固定同窗口正文 → 可替换的文本/EDU/图聚合 → 统一四类输出 → 独立开发选模与校准 → 域内、留域、外部迁移、低误报、成本报告。它是实验模块化架构，不是把所有候选拼成一个大模型。
