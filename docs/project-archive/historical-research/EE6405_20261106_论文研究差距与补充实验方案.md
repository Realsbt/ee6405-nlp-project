# EE6405：从课程项目到研究论文

日期：2026-11-06。状态：研究方案，新增实验未执行，不是论文成品。

依据：已审查的小组仓库 main@7eb3319；2026-11-06 检索的原始论文、作者仓库及数据说明。采用 literature-review skill 的问题界定、原始来源核验和证据分层流程。本次为定向叙述性研究审查，不是系统综述，不声称文献穷尽或研究方向首次提出。

## 1. 两个必须澄清的概念

### 编辑过程是怎么得到的

RACE 原论文附录 A.1 说明：四分类标签来自 HART 的记录 ID、content_source 和 language_source，而非让检测器猜出后再当作真值。[R1]

| 标签 | 原论文描述的映射 |
|---|---|
| human_written | 原始人类文本记录，没有 gen/、rep/ 等衍生前缀 |
| human_ai_polished | rep/ 记录，语言来源标记为 rephrase |
| ai_generated | 机器来源的 gen/ 记录，也包含由另一模型继续修改的部分 AI-to-AI 链 |
| ai_humanized | hum/gen/ 中 language_source 为 humanize:human 或 humanize:tool 的记录 |

小组 prepare_data.py 直接读取 RACE 发布文件中的 label，不从 HART 原始元数据重新构造标签。因此目前证据是“使用作者发布标签”，不能说小组已独立验证所有创作历史。

训练时模型得到正文与标签；推理时只根据最终正文预测类别，不得到版本历史。RST 树是正文的篇章解析，不是编辑日志。模型不能回答哪一句由谁在何时改过，也不能仅凭最终文字证明现实作者身份。

建议新增 provenance 表：item_id、source_id、parent_id、原始元数据、操作、creator 类型、editor 类型、生成模型、编辑工具、映射标签、映射规则版本、匹配状态。缺失字段保留 unknown，绝不根据预测回填真实来源。

### 除三条路线外，还有什么

原来的 TF-IDF、RoBERTa、RACE 是三种实验模型，不是整个领域只有三个互斥类别。

| 方法族或研究方向 | 代表来源 | 本项目的适用性 |
|---|---|---|
| 语言模型概率与零样本检测 | Fast-DetectGPT [R3]、Binoculars [R4] | 可增加一个不同原理的比较器；原生二分类分数不能直接当四分类输出 |
| 细粒度监督检测 | LLM-DetectAIve [R5] | 相关工作重点；使用权重前核对训练数据与测试重叠 |
| 篇章特征 | Discourse Motifs [R6] | 可比较简单篇章统计，判断复杂图网络是否必要 |
| 内容与表达分离 | HART / 2D Detection [R2] | 与 creator-editor 问题直接相关，但不能宣称本组首创 |
| 生成时水印 | A Watermark for Large Language Models [R7] | 需生成端配合，不适合作为任意现存 HART 文本的直接基线 |
| 渐进编辑、句子或片段级识别 | 本方案提出的后续研究方向，未在本次确立具体基准 | 适合未来扩展；会改变任务与标注要求 |

推荐优先补“与研究假设直接相关的图结构对照”，而不是把所有模型都实现一遍。

## 2. 论文定位与研究问题

建议工作标题：

**Do Discourse Graphs Help Fine-Grained Text Provenance Detection? A Controlled Replication and Robustness Study**

中文：篇章图是否有助于细粒度文本来源识别？一项受控复现与鲁棒性研究。

这是暂定定位，不代表已有新颖性结论或可保证发表。课程研究报告和正式投稿的要求不同；投稿前还需确定目标 venue、篇幅、匿名要求及补全文献比较。

研究问题：

1. RQ1：在词汇窗口和可用结构信息一致时，真实篇章关系是否比无图或结构对照更有效？
2. RQ2：SupCon 的收益是否依赖架构、数据划分和微调预算？
3. RQ3：模型学到的是可迁移的创作/编辑特征，还是特定领域、生成模型或编辑工具的特征？
4. RQ4：在限制人工文本误报的条件下，模型还能识别多少 AI 来源文本？

RACE 原论文已经有分组划分（附录 B.2），并报告 Macro-AUROC 和低误报条件下的召回。因此不能把这些本身包装成原创。小组现有 Macro-F1 排序也不能直接否定原论文采用不同指标、训练条件得到的结论。[R1]

潜在贡献应是完成控制实验后得到的具体发现，例如“某种结构增益只在特定窗口/预算下存在”。不能先把预期结论写成事实。

## 3. 已有证据及缺口

仓库保存了 13 次 HART 运行、四组单种子 HC3 辅助输出及完整 2×2 三种子矩阵。前序检查从保存预测重新计算指标并通过一致性核验；这不等于本次完成原始数据与权重重放。

已有证据可用于描述本组固定协议下的模型表现、种子差异和外部二分类退化。

目前不能直接支持：

- 实际编辑历史重建或真实作者鉴定。
- 图结构本身的独立收益：pooling、参数量、可见全文结构等仍有差异。
- 普遍跨域泛化：当前 HART 分域结果不是留一领域训练测试。
- 四分类外部泛化：HC3 没有四类真值。
- 完整重现原论文或推翻其结论：训练预算、划分和主要评价指标尚未完全对齐。

依据仓库 README.zh-CN.md、experiments/METHOD_NOTES.md、experiments/reports/comparison/REPORT.md、experiments/reports/auxiliary/REPORT.md、docs/ABLATION_2X2.md。

## 4. 按优先级执行的实验方案

以下都是建议，新增输出不得标记 completed，直到实际执行并审核。

### P0：先固定问题、标签和比较协议

工作：

- 对照 HART 原始记录，审核四类映射；分别统计真人改写与工具改写，缺失来源单列。
- 比较原论文与本组的数据版本、划分、微调层、学习率、batch、SupCon、输入长度、parser、选模指标。
- 明确主要指标为 Macro-F1，辅助报告 Macro-AUROC、每类 precision/recall/F1、成本及预先定义的低误报评价。
- 冻结新增实验列表与验证集选择规则。已查看过的旧测试集属于探索性分析；改变随机种子或重切已见语料不产生真正未接触的外部测试。

验收：标签映射表、协议差异表、预定实验矩阵，所有未知项标清；不给未核验标签强行补值。

### P1：真正检验图结构，而非只比较模型名字

建议最小结构实验：

| 配置 | 目的 |
|---|---|
| 同窗口 RoBERTa | 语义基线 |
| 同窗口 RACE + 正常关系 | 图模型 |
| 同窗口 RACE + 扰乱关系类型 | 检查关系语义是否重要；不声称隔离所有图效应 |
| 同窗口 EDU pooling + 匹配分类头 | 检查 EDU 聚合与图消息传递的区别 |

所有模型必须使用完全相同的文本片段。建议截断正文后重新解析，避免沿用全文解析时引入截断外信息。保留既有全文结构结果作为单独条件，不覆盖旧结果。

结构对照要从训练开始应用，并明确映射方式、随机种子及对图尺寸的影响；仅在测试时破坏图属于敏感性测试，不能替代重训消融。若做随机树，需保证图合法和相近尺寸，且承认结构分布改变的影响。

先固定一个损失设置做机制实验，至少复用三个种子。若预算充足，再扩展损失维度。先测试一个小规模训练 smoke，估算资源后锁定正式预算。

验收：同窗口覆盖审计、参数量、三种子结果、与正常图配对差值、失败/缺失运行清单。负结果照实报告。

### P1：加入真正的泛化测试

优先做 HART 留一领域：四个领域轮流作为测试域，训练/验证只来自其余领域。不得在目标领域选模型或阈值；同源及近重复关联必须跨域整体隔离。

建议先比较 RoBERTa+SupCon 和 RACE+SupCon，固定同窗口、parser 与训练规则，四个目标域各三个种子，共 24 次运行。这个数量是建议预算，不是当前完成情况；若负担过大，先预先指定一个目标域，结论也只限该域。

独立外部评估候选：

- MixSet [R8]：与混合编辑场景贴近，但各操作的标签含义不一定与 HART 相同。先写映射表，再决定哪些子集纳入；不能把所有 rewrite 自动视为 polish。
- RAID [R9]：适合补充二分类生成模型/攻击鲁棒性，不提供与 HART 等价的四类过程真值。

外部数据是否可获得、许可、完整 lineage、与 HART 的重叠都需实际检查。本次没有下载或核验这些候选数据。新增数据固定采样后保留最终测试，禁止依据模型表现挑选样本。

若生成模型元数据不完整，不得用 model_name 单字段武断实现“未见生成器测试”：它可能描述编辑者而非最初生成者。需先恢复角色信息，再按相关来源组整体隔离。

### P1：补充风险指标与不确定性

- 分开报告四分类结果与明确 creator 定义下的二分类结果。
- 增加验证集确定的低误报阈值，测试时同时报告实际 FPR 和 TPR。不能在测试集找满足 1% FPR 的阈值后，把它当部署性能。
- 若同时报告测试 ROC 的 TPR@1%FPR，标为描述性曲线指标，与验证集锁定阈值结果分表。
- 对同源组进行配对 bootstrap，保留训练种子差异；训练种子 SD 不是置信区间。
- HC3 按 question-pair 重采样，而不是将同一问题的两条回答视为完全独立。
- 500 条人类测试样本中，1% 只对应 5 个误报，不能把微小差异解释为稳定的低误报优势。
- 给出 Brier score 或可靠性图；校准器仅在验证集拟合。无足够样本时不作极低 FPR 承诺。

低误报评估的动机见 [R10]；其余为本组建议协议。

### P2：增加一个真正不同的比较方法

若选择 Binoculars 或 Fast-DetectGPT：

- 原生输出先用于二分类、相同测试集和明确相同的目标定义，且把训练数据使用量与计算成本差异写清。
- 若将分数/特征接小型分类头用于四分类，训练与校准只用训练/验证集，命名为“adapted supervised baseline”，不再称为原始零样本四分类方法。
- 现成检测器的训练语料若包含 HART 来源，标注泄漏风险；不能因为无需本组训练便视为无泄漏。

不建议同时增加多个大模型、水印系统和局部片段检测。优先完成 P0/P1，让论文有清晰答案。

## 5. 个人任务推进顺序

不依赖团队人数，不分配成员；按依赖关系逐项推进，只有实际执行并验证后才能标记完成。

1. 核验原论文与代码协议，输出差异表及未确认事项。
2. 审计标签证据，区分发布标签、原始来源记录和推断信息。
3. 利用已有预测补充概率可靠性分析；不在测试集重新选阈值或调参。
4. 获取并核验原始数据、parser、权重和运行环境，建立新实验资源目录。
5. 实现并测试同窗口图结构对照，先 smoke，再运行预定种子。
6. 运行留域与独立外部评估，按预先确定的协议汇总。
7. 整理论文正文、图表、引用和可复现材料，不将待执行实验写成结果。

## 6. 论文结构和最低完成标准

建议结构：Introduction → Related Work → Task and Provenance → Controlled Protocol → Results → Mechanism and Transfer Analysis → Limitations and Ethics → Reproducibility。

最低图表：

1. 标签来源/数据流与同源分组示意。
2. 原论文与本组协议差异表。
3. 主实验与已有 2×2 消融结果。
4. 同窗口结构对照。
5. 未见领域或真正独立数据测试。
6. 低误报结果、每类错误与计算成本。

课程论文目标：清楚、诚实、可复核地呈现已有实验，加最关键控制实验即可形成扎实报告。

投稿目标：还需要证明相对现有工作提供了非平凡的新知识，独立测试和机制结论足够可信，并根据目标 venue 评估新颖性。只增加第三个数据集或第四种模型，不自动构成贡献。负结果也必须排除预算不足、实现差异和不公平比较等替代解释。

当前建议：先完成来源审计与协议差异表，再实施同窗口图结构对照；随后做留域与外部评估。写作可同步起草，但所有新增结果位置保持“待执行”，不编造摘要里的提升数值。
