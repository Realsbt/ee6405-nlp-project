About this page
A local document-explanation workbench for the EE6405 text-provenance project. Everything runs on your machine.
What it does
Classifies an English document into four writing categories, then measures how each discourse unit affects one selected class score.
Two perspectives
Explore & Edit covers the document map, independent passage predictions, input coverage and what-if editing. Explain Prediction covers document influence and the RACE discourse graph.
How to use it
Paste or import text, pick a model, then choose Analyze document. The prediction appears first; unit metadata loads separately. Use Map to move between paragraphs, then Explain selected unit, Explain visible units or Quick preview to measure influence on demand.
Four models
TF-IDF, RoBERTa, RACE and RACE without contrastive loss. Each is an independent classifier; scores are never fused.
Reading the output
Whole-document scores on the right never change. Left-side colors show the effect of suppressing a unit on the selected class, not a passage label.
What-if editing
Editing freezes the Original prediction. Reanalyze runs a real prediction on the revised text. Those before/after differences are not feature-suppression effects.
Privacy
Text goes only to the local service on this machine. Nothing is uploaded, stored or sent to a third party.
Limits
Scores are learned patterns, not calibrated authorship probabilities or proof of who wrote the text. Stopping the browser does not cancel a running forward pass. Units outside the lexical window have no influence estimate, not zero influence.
