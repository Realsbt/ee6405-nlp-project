## 2. 前端设计（Text Lab）

### 2.1 交付形态

| 形态 | 位置 | 说明 |
|---|---|---|

线上地址：`https://realsbt.github.io/ee6405-nlp-project/`

### 2.2 核心功能

**Document Map（文档地图）**
把文档切成可解释单元，每个单元标注状态：已计算 / 未计算 / 超出窗口。RACE 用真实 RST EDU，其余模型用确定性显示分段。

**Focus Graph（聚焦图）**
展示 RACE 的 RST 树结构，可点击节点查看该 EDU 对最终分类的影响。

**On-demand Explanation（按需解释）**
不预先计算全部单元，只算用户点开的。配合 LRU 缓存（容量 4）与版本化 key，避免重复计算。

**What-if Editing（假设编辑）**
用户修改文本后重新打分，观察预测如何变化。

**Coverage（覆盖率）**
明确显示「N of M characters」与「T / 512 tokens」，超出窗口的部分标注为 `Outside lexical window`，**不显示为 0 影响**。

### 2.3 评分机制（关键设计）

对每个单元做**内部特征干预**，返回四类的 `without_scores`：

$$\Delta_{pp}[c] = 100 \times \left( p_{\text{original}}[c] - p_{\text{without}}[c] \right)$$

正值表示该单元支持当前预测类别，负值表示反对。四类差值之和约为零。

**三种模型三种干预方式**（不可直接横向比较）：

| 模型 | 干预方式 |
|---|---|
| RACE | 把选中 EDU 的内容向量置为类型嵌入，并从所有祖先关系均值中扣除其贡献 |
| RoBERTa | 在编码前把选中 token 的词嵌入置零，重跑编码器 |
| TF-IDF | 把选中分段的词/二元组特征从稀疏向量中移除 |

**重要声明**：这是**条件性内部特征探针**，不是作者身份的因果估计，也不是全文删除。

### 2.4 窗口限制（诚实标注）

`roberta-base` 的 `max_position_embeddings = 514`，所以 512 token 是架构硬限制。9,000 字符文档实测：

| 模型 | 窗口 | 覆盖 | 可解释单元 |
|---|---|---|---|
| TF-IDF | 全文 | 9,000 / 9,000（100%） | 68 / 68 |
| RoBERTa | 512 token | 2,859 / 9,000（32%） | 22 / 68 |
| RACE | 512 token | 2,859 / 9,000（32%） | 57 / 179 |

TF-IDF 无位置嵌入，因此不受此限制，已改为读全文。

## 3. 模型评分与效果排序

### 3.1 单一篇输入分类（可部署）

**定义**：只给一段文字，无任何组信息。

**最佳模型**：13 模型逻辑回归堆叠（12 神经 + 1 TF-IDF，52 维概率输入，验证集拟合）。

| 指标 | 值 |
|---|---:|
| 准确率 | **95.05%** |
| Macro-F1 | **93.05%** |
| 测试样本 | 3,194 |

**逐类召回**：

| 类别 | 样本 | 召回 |
|---|---:|---:|
| human_written | 798 | 98.87% |
| human_ai_polished | 798 | 93.86% |
| ai_generated | 1,371 | 96.06% |
| **ai_humanized** | 227 | **79.74%** |

**单一篇效果排序**：

| 排名 | 模型 | 准确率 | Macro-F1 |
|---:|---|---:|---:|
| 1 | **13 模型堆叠** | **95.05%** | **93.05%** |
| 2 | 13 模型等权平均 | 94.65% | 92.14% |
| 3 | logreg on 12 strong | 94.52% | 92.51% |
| 4 | 非负权重融合 | 94.33% | 91.89% |
| 5 | E30 等权融合（复合 Top 3） | 94.24% | 92.02% |
| 6 | E01 单窗口 | 93.71% | 91.14% |
| 7 | E26 头/中/尾 | 93.68% | 91.17% |
| 8 | RoBERTa · CE+SupCon | 93.58% | 91.15% |
| 9 | RoBERTa · CE | 93.45% | 90.72% |
| 10 | RACE · CE+SupCon | 93.08% | 90.37% |
| 11 | RACE · CE | 92.83% | 89.92% |
| 12 | TF-IDF + LR | 85.32% | 79.40% |

**部署限制**（必须声明）：

1. `ai_humanized` 是短板（79.74%），内部异质：工具改写 88.24%，人类改写仅 42.11%。
2. 置信度不可用于拒答：错误时平均置信度仍 0.811（正确时 0.963）。
3. 95.05% 是同分布数字；短文本（<1k，n=375）只有 89.87%。

### 3.2 多篇输入分类（协议内）

**定义**：同时拿到同组 4 条文档，且该批次标签构成符合两种模式之一。

**最佳模型**：堆叠 + 组约束解码 + 组内 pairwise 判别器。

| 指标 | 值 |
|---|---:|
| 准确率 | **97.78%** |
| Macro-F1 | **95.90%** |
| 人类改写召回 | 52.63%（从 43.86% 提升） |

**多篇效果排序**：

| 排名 | 方法 | 准确率 | Macro-F1 |
|---:|---|---:|---:|
| 1 | **堆叠 + 组约束 + pairwise** | **97.78%** | **95.90%** |
| 2 | 堆叠 + 组约束 | 97.56% | 95.40% |
| 3 | E30 + 组约束 + pairwise | 96.81% | — |
| 4 | 堆叠（无约束） | 95.05% | 93.05% |
| 5 | E30（无约束） | 94.24% | 92.02% |

**关键澄清**：97.78% 是**评估协议数字，不是产品指标**。约束解码本身的真实贡献是 **+2.57 到 +2.72 pp**，不是此前宣称的 +3.53 pp（差额来自堆叠）。

**多篇方法的限制**：

| 限制 | 影响 |
|---|---|
| 需要完整 4 条 | 3 条时只涨 0.88 pp，2 条涨 0.20 pp，**单文档完全无效** |
| 分布外静默失败 | 只允许两种模式，遇到违反的数据集不会降级 |
| 域间先验波动 | HUM 比例按域 25.63%–31.00%，未按域调整 |
| 2 条文档被跳过 | 799 组中 1 组只有 2 条 |

### 3.3 按粒度分类

| 粒度 | 准确率 | Macro-F1 | 说明 |
|---|---:|---:|---|
| 二分类（人 vs AI） | 99.25% | 99.00% | 最可靠 |
| 三分类 | 96.23% | 96.13% | n=2,967 |
| **四分类（主任务）** | **94.24%** | **92.02%** | E30 基线 |
| 五分类（拆分 humanized） | 94.24% | **86.56%** | 逐类 F1 [98.33, 93.24, 94.26, 87.72, 59.26] |

**结论**：四分类是主任务，其他粒度作为辅助分析。五分类的 Macro-F1 骤降说明 `ai_humanized` 内部异质性严重。

## 4. 尝试过的方向与结果

### 4.1 成功的

| 方向 | 结果 | 产出 |
|---|---|---|
| 2×2 消融（架构 × SupCon） | SupCon 在 RoBERTa +0.44 pp、RACE +0.45 pp；交互项 +0.01 pp | `ABLATION_2X2.md`、`ablation_2x2.png` |
| 13 模型堆叠 | 95.05% / 93.05%，Δ +0.81 pp，CI [+0.25, +1.38] | `STACKING.md`、`stacking.png` |
| 组约束解码 | 97.56%，Δ +3.31 pp | `CONSTRAINED_DECODING.md` |
| 组内 pairwise 判别器 | 97.78%，人类改写 43.86% → 52.63% | 同上 |
| 短文本专用模型 | +3.47 pp，CI [+0.00, +6.80]，P=0.974（下界触零） | `REVISED_EVALUATION.md` |
| fp16 推理加速 | RoBERTa 3.20×、RACE 1.20×，argmax 100% 一致 | `CONSTRAINED_DECODING.md` |
| 信息论方法 M1/M2/M3 | M2+E30 融合 94.43%，Δ +0.19 pp，CI [−0.09, +0.47]（不显著） | `INFO_STYLOMETRY.md` |

### 4.2 失败的（已记录，不隐藏）

| 方向 | 结果 |
|---|---|
| 组级分类器 | 97.65%，−0.13 pp |
| 组级分类器 + 相似度特征 | 93.23%，无变化 |
| pairwise + 10 个文本特征 | 召回 83.70% → 84.14%，噪声内 |
| pairwise 正则化调参（C=0.01–3.0） | 无变化 |
| 减少模型数量（top-k） | k=1..12 全部不显著 |
| **表面线索感知重加权** | **净 +3 条，Macro-F1 不变，目标子群体反而略降** |

### 4.3 主动撤回的结论

| 原结论 | 撤回原因 |
|---|---|
| 「配对模型学到同文档对比能力」 | 跨文档配对仍有 80.70%，只比真实同源低 7 pp |
| 「约束解码贡献 +3.53 pp」 | 基线未加约束，公平对比应为 +2.57/+2.72 pp |
| 「AI-generated 位于特征空间中心」 | 混淆矩阵不说明内部表示几何 |
| 「逗号是唯一可用线索」 | 只检查了 18 个表层特征 |
| 「82% 组全对 → 接近上限」 | $0.9505^4 \approx 81.6\%$，不构成证据 |
| 「不需要再修改模型」 | 只支持「线索不典型时更易错」，不支持「无法识别」 |

## 5. 评估可信度工作

这是本项目最有价值的部分之一：**多次发现并修正自己的评估缺陷**。

| 审计项 | 发现 | 修正 |
|---|---|---|
| 短文本模型泄漏 | 原版用**测试集**选变体和权重 | 改为验证集选择，结果从 +3.79 pp 降为 +3.47 pp，CI 下界触零 |
| 堆叠泄漏 | 原版在测试集交叉拟合得 95.15% | 改为验证集拟合，95.05% |
| 组结构增益 | 需证明不是解码器技巧 | 两个安慰剂各 200 轮，全部崩塌（72.75% / 93.63%），p < 0.005 |
| 人类改写困难 | 需证明是标签问题 | 容量扫描、平衡池、手工特征全部无效；但配对 87.72% 被证伪为通用风格信号 |
| 堆叠超参数 | 手选且非最优 | 36 组网格：跨度 0.88 pp > 增益 0.81 pp；验证集选择可得 95.30% |
| 组大小 | 此前写「每组恰好 4 条」 | 实际 798×4 + 1 组 2 条 = 3,194 |

## 7. 关于重加权实验的结论（本轮停止条件）

按预定停止条件，**本版表面线索重加权暂不采用，不替换现有模型**。新 checkpoint 保留为实验产物，不默认部署。

**写进报告的结论**：

> 在同一 RoBERTa checkpoint、相同额外三轮训练预算和相同优化设置下，基于组隔离折外表面线索预测的样本重加权，相对普通追加训练仅净增加三条正确预测，未观察到 Macro-F1 改善，也未改善目标 GEN–HUM 困难子群体。因此，本配置不作为最终模型升级方案。该结果限制的是本次重加权方案的有效性，并不能证明表面线索没有作用、模型容量已经足够，或剩余错误无法减少。

**这轮最有价值的不是多判对三篇，而是完成了一次能够否定自身改进假设的受控实验。**
