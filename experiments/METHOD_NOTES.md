# 模型与实验说明：对应实际代码

用于审核代码和准备真人讲解。这里描述本机实现的行为；完整配置、来源、分数与局限分别见 `configs/neural_v1.json`、`SOURCES.md` 和统一实验报告。

## 任务：学习四种发布标签

| 标签 | 数据中的操作定义 |
|---|---|
| human_written | 人工原文 |
| human_ai_polished | 人工内容经 AI 润色 |
| ai_generated | AI 内容，含发布版本的 AI→AI 改写链 |
| ai_humanized | AI 内容经人工或工具改写 |

四类把创作与后续处理区分开。模型从最后的文本及可用篇章结构学习这些标签，没有直接观察真实创作历史。本实现是一个四分类网络，不是两个独立的创作者/编辑者分类器；也不能把 `ai_humanized` 等同于已证明有真人编辑。

## TF-IDF＋逻辑回归

输入为首 512 个 RoBERTa tokens 所覆盖的原文字符前缀 `model_text`。只在训练集学习词表和 IDF：词 1–2 gram、最多 50,000 特征、最小文档频次 2，使用 sublinear TF、默认平滑 IDF 与 L2 向量归一化。

对非零词频，sublinear TF 是 $1+\log(tf)$；平滑 IDF 是 $1+\log((N+1)/(df+1))$。高频但普遍的词权重较低，文档中相对有区分力的词组可以获得较高权重。

四类逻辑回归使用 L2 正则、LBFGS 和 balanced 类别权重。只在 `[0.1,1,10]` 中按验证集 Macro-F1 选 C（并列取较小 C），选中 10；C 越大，正则相对越弱。没有把验证集加入拟合，也没有在测试集上选 C。对应 `train_tfidf.py`。

## RoBERTa 对照

文本经 RoBERTa-base 得到每个 token 的 768 维表示，取位置 0 的 CLS 表示送入 768 维隐藏层的 MLP，输出四个 logits，再经 softmax 得到四类分数。

基础预训练权重相同；只解冻最后一个编码层，任务分类头可训练。冻结参数不意味着把其输出缓存成常量：训练模式下仍有 dropout。训练使用 BF16，验证和测试使用 FP32。实现复用官方 `FlexibleBaselineModel`。

加载日志中可能提示 pooler 权重未从 masked-LM checkpoint 初始化。这里两个模型均直接使用 `last_hidden_state`，不使用 `pooler_output`；其后还会严格加载各自已保存的完整任务 checkpoint。该提示不表示已使用的编码层缺少预训练权重。

## RACE：EDU、关系图与 root 表示

1. RST parser 把完整正文切分为基本篇章单元 EDU，并预测它们之间的关系树。训练数据使用作者发布的树；Demo 和 HC3 使用本机实际 parser。
2. 对词汇窗口内每个 EDU，把其对应 RoBERTa token 表示取平均。关系节点用其可见后代 EDU 的表示取平均；没有可见后代时初始内容向量为零。
3. 给 EDU/关系节点加入不同的节点类型向量，再投影到 128 维。
4. 两层 RGCN 按边类型变换并聚合邻居，隐藏维度 512，层间使用 ELU。18 种基础篇章关系展开为当前配置的 54 个边类型，用 10 组 basis 共享关系参数。
5. 取图 root 的 512 维表示，送入 MLP 输出四个 logits。关系标签通过边类型参与传播，不是另一个人工作者身份输入。

全篇 RST 的截断外 EDU 节点会被 graph builder 删除，关系节点及其连接仍保留，所以结构信息可超出前 512-token 词汇窗口。主结果存在这一信息差异；未截断子集和坐标质量子集只能帮助描述，不能替代完全匹配信息的随机控制实验。

当前官方 forward 没有使用配置中的 `gnn_dropout` 字段；实际有 projection dropout 和 classifier dropout（均为 0.1）。本项目保留官方网络行为，不把一个未使用字段说成已经产生正则作用。RoBERTa 与 RACE 的分类头维度和额外参数也不同，因此主方法差值不能完全归因于图结构。对应官方 `models/flexible_model.py`、`utils/flexible_graph_builder.py` 与本项目 `graph_data.py`。

## 交叉熵、监督对比与消融

交叉熵推动正确标签的分数更高：$L_{CE}=-\frac{1}{N}\sum_i\log p(y_i|x_i)$。

开启 SupCon 时，RoBERTa 将现有 768 维 CLS 表示、RACE 将现有 512 维 root 表示分别归一化为 $z_i$，没有增加额外投影头。同标签的其他样本构成正例集合 $P(i)$，对比损失为：

$$
L_{SupCon}=\frac{1}{N}\sum_i\frac{-1}{|P(i)|}\sum_{p\in P(i)}
\log\frac{\exp(z_i^Tz_p/\tau)}{\sum_{a\ne i}\exp(z_i^Tz_a/\tau)}.
$$

温度 $\tau=0.07$；总损失为 $L_{CE}+1.0L_{SupCon}$。batch 16 内每类 4 条，因此每个锚点都有 3 个同标签正例。损失采用同标签/不同标签关系，并没有从外部获得创作者或编辑者的真实身份。

`race_no_supcon` 保留相同 RACE 架构，只关闭该额外损失；`roberta_supcon` 在同一 RoBERTa 架构上开启它。架构与损失开关独立，四格均使用 3407、42、2026；沿用相同数据、采样及优化规则。完成状态和结果见统一报告；计划与运行约定见 [2×2 消融](../docs/ABLATION_2X2.md)。同种子差值分别描述两种架构内的损失效应、相同损失下的架构差异及两者交互。由于 pooling、表示维度、参数量和可见结构信息仍不同，不能单独证明篇章图的因果效应。

## 训练与评估怎样隔离

神经模型统一 batch 16、学习率 2.9e-5、最多 20 轮、10% warmup、AdamW、梯度裁剪 1.0，验证 Macro-F1 连续 5 轮不改善则停止。每轮平衡采样约 11,184 次：少数类循环取样，多数类取随机子集；固定标签与采样规则对所有神经模型一致。

训练只读取训练和验证数据。保存验证集分数最高的 checkpoint 后，再打开保留测试分区。测试结果不参与 checkpoint 选择、参数修改或重新划分。每次运行保存源码快照、配置、模型、事件记录，并重载模型复算完整 3,194 条测试预测。

Accuracy 会较多反映大类；Macro-F1 对四类的 F1 等权，便于看到改写 AI 少数类。Macro-AUROC 对每类做 OvR 排序再平均，与固定 argmax 分类反映不同性质。缺失类别的 AUROC 为 null，不用零填充。测试 ROC 上的 TPR@1%FPR 是描述性值，不是经过独立校准的部署阈值。

三种子 SD 描述同一划分下训练随机性的波动；成对差异先在相同种子内计算，再汇总均值与样本 SD，SD 不等于置信区间。本轮补充矩阵在查看原有结果后确定，沿用原测试集，不构成新增独立验证。按来源关联分组的 bootstrap 描述两个已拟合模型在当前测试来源组上的条件抽样波动。它们都不等于跨数据集、跨划分或未见生成模型的普遍保证。

## HC3 与 Demo 能证明什么

HC3 只有人类/ChatGPT 二分类标签，预先固定 $s=P(ai\_generated)+P(ai\_humanized)$、阈值 0.5。`human_ai_polished` 仍归在人类创作者一侧。观察到很多 ChatGPT 回答被分到该输出，是辅助任务与分布差异的证据候选；把它重新算成 AI 会改变主要评估定义。

Demo 的端到端耗时包含实际需要的模型加载、分词、RST 和分类。冷 parser 加载与后续解析分开记录；只报告 classifier 前向会漏掉重要成本。无标签示例只验证可用性，不能计入准确率。四类 softmax 分数未经概率校准。
